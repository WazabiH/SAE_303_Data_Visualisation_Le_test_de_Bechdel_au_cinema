# Héroïnes & Réalités – Analyse de la représentation des femmes dans le cinéma

## Présentation

Ce projet a été réalisé dans le cadre de la SAE 3.03 du BUT Métiers du Multimédia et de l'Internet (MMI).

L'objectif était d'exploiter et de valoriser un jeu de données portant sur la représentation des femmes dans le cinéma à travers le test de Bechdel. Le projet prend la forme d'un site web permettant de consulter, explorer et comprendre les résultats de cette analyse de manière accessible et visuelle.

## Contexte

Le test de Bechdel est un indicateur permettant d'évaluer la place accordée aux personnages féminins dans une œuvre de fiction.

À travers ce projet, nous avons étudié plusieurs films afin d'analyser les tendances de représentation des femmes dans l'industrie cinématographique et de sensibiliser le public à cette thématique.

## Fonctionnalités

* Présentation du projet et de sa démarche
